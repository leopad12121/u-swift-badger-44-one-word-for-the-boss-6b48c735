Exactly one word for the boss: praise, used as a verdict. Written after scoring eight fresh candidates against the judge's criteria (a single word describing a boss, funny on its own, rings true, fresh, travels across industries); the winner scored 22/25 and was revised once before submission.

## Run it

```bash
python3 main.py
```

This writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
